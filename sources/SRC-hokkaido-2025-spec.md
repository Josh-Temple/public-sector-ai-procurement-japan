# Source notes

RAGを利用した生成AI実証の公式仕様書。

主な確認事項:
- サービス提供期間 2025-07-01〜2026-03-31
- 約12,000人分のアカウント
- 30RAG以上・総容量100GB以上
- 回答の参照文書・参照箇所表示
- 入力情報をAI学習に利用しない
- ISMAP登録、国内サービス施設、日本法・国内裁判管轄
- 24時間365日、研修2回以上、RAG導入効果の中間・最終分析

## Reuse caution

仕様書上のサービス提供開始日は契約上の期間であり、実際の稼働開始確認とは分ける。公開Q&Aによる定義・補足は `SRC-hokkaido-2025-page` も確認する。
