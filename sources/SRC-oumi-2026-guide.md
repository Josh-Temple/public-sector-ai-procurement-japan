# Source notes

実施要領は、選定後にサービス仕様書を協議して作成し、各市が個別に見積・サービス利用契約を行うと定める。基本契約に加えて市ごとの利用申込・契約がある構造で、契約期間と実際のサービス利用期間は異なり得る。契約最終仕様や締結済み契約を確認した資料ではない。
