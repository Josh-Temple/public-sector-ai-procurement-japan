# Source notes

公開質問回答9件。

重要な解釈:
- 生成AIモデルは固定指定せず、提案者が選定して提案書へ記載
- 100万文字/月以上は必須
- 文字数上限なしは提案事項で、上限に応じて加点
- 問い合わせ時間・方法は市想定と異なっても提案書へ明記して評価対象にできる
- 提案事項も契約限度額内に含める

## Reuse caution

必須要件と加点対象の提案事項を混同しない。
