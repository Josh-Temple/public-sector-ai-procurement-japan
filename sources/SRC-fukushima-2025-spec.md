# Source notes

生成AIサービスを実証導入し、利用頻度・ユースケース傾向を分析評価して導入本格化を目指す公募時仕様。

主な要件:
- SaaS型ブラウザ利用
- ChatGPTまたはGeminiの少なくとも一方
- ChatGPT-3.5 turbo相当以上
- 入力情報をAI学習に利用しない
- 機密情報漏えい防止
- ログ閲覧・エクスポート
- 50人同時接続
- 月500万文字
- 国内サーバ設置または国内準拠法
- 生成AI基礎・プロンプトエンジニアリング等の研修
- Microsoft 365 Copilot 53ライセンス

## Reuse caution

後続Q&Aで複数要件の適用範囲が具体化される。応募時の有効要件は `SRC-fukushima-2025-qa` と併読する。
