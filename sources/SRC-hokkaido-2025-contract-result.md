# Source notes

公式随意契約結果。

確認できる事項:
- 契約日 2025-06-11
- 契約相手方 東日本電信電話株式会社
- 契約金額 21,780,000円

選定理由欄は、生成AI活用推進業務のプロポーザル審査委員会を2025-05-23に開催したと記載する。

## Reuse caution

契約結果一覧は契約締結自体の証拠だが、契約最終仕様・業務処理要領の本文を示す資料ではない。実稼働開始の証拠にも使わない。
