# Source notes

公式の公募型プロポーザル実施説明書。

審査は170点で、実施体制等20点、企画提案内容140点、見積価格10点。順位点合計が最も高い提案者を特定者とする。

契約について、採択された企画提案は契約締結時に修正・変更される場合があり、契約書・業務処理要領は提案内容を踏まえて別途提示される。

## Reuse caution

公募仕様・選定結果だけから契約最終要求を再構成しない。
