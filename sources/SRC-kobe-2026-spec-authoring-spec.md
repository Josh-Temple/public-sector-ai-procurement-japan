# Source notes

生成AIを用いた仕様書のレビュー・作成支援を、RAG、入力フォーム、フロー登録、利用環境、非機能要件まで含めて定義した公式仕様書。

## Evidence locators

- PDF p.1-2、2(1)-(2)・5(2): 仕様書品質の標準化、レビュー工数削減、ナレッジ再利用を目的とし、年間約300件の仕様書作成を想定。
- PDF p.3、6(1) No.1-1〜1-7: 文書間・文書内整合性確認、RAG等を参照した修正案生成、利用者による採用・不採用、指摘一覧、ベース文書選択、入力フォーム、1GB以上の添付。
- PDF p.4、6(1) No.1-8〜1-11 / 6(2): RAG等を参照した仕様書案生成、自然文による修正、レビューと修正の反復、Word出力、フロー作成・編集・削除・権限・プレビュー。
- PDF p.4、6(3)(2)-(4): 1,000アカウント以上、100名以上同時アクセス、仮想ブラウザまたはLGWAN利用を想定し、LGWAN接続は望ましい要件。
- PDF p.5、6(3)(6)-(9): RAGはWord/Excel/PDF対応、1TB以上。AI条例第7条該当時はAzure OpenAI Serviceを前提とし、他LLM選択は望ましい。非機能要求はIPAレベル0または1相当で、事前合意の保守停止・障害時の業務停止を許容。AI基本指針・リスクアセスメント・情報セキュリティポリシーに従う。

## Reuse caution
