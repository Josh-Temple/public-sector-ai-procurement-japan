# Source notes

仕様書作成支援AIの公募手続、質問回答、提案評価、契約方法を示す公式実施要領。

## Evidence locators

- PDF p.1、3(1) 契約の方法: 契約内容は市と協議のうえ、仕様書及び企画提案書に基づき決定する。
- PDF p.2、5(5)/(9): 契約締結・事業開始は4月中旬予定、業務期間は契約締結日から2027-03-31まで。予定日を実際の契約日・稼働確認へ読み替えない。
- PDF p.4、6(2)オ 回答方法: 質問要旨と市の回答を参加予定者全員へ電子メールで回答し、市回答は入札説明書等を補足する効力を持つ。参加資格等の質問回答は原則非公表。
- PDF p.7、7(2): 評価点と価格点により契約候補者を選定する。
- PDF p.8、7(5): 選定結果は神戸市Webで公表する。

## Reuse caution

公開仕様・公開選定結果・公募時の契約書案があっても、参加者向け質問回答や協議後の最終契約内容を公開資料だけで完全に再構成できるとは限らない。

公式ページに「契約金額」が掲載されていても、それだけで署名済み契約本文、契約締結日、最終仕様、実稼働を確認したことにはしない。
