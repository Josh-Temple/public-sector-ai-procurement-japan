# Source notes

公式実施要領。

重要な契約ルール:
1. 企画提案書作成に関する質問回答
2. 仕様書
3. 企画提案書等

の順で齟齬解消時の優先順位を定める。

ただし、企画提案書が質問回答・仕様書の水準を上回る部分は、その上位部分に限って企画提案書を優先する。

その他の齟齬は市と受託候補者が協議して優先関係を判断する。

質問回答は参加者全員にEメールで回答するとされ、公開本文は確認できない。

## Reuse caution

公開仕様書は契約最終仕様の完全な代替ではない。公開資料から確定できるのは、公募時の最低限要件と公開された契約決定ルールまで。

## Evidence locators

- PDF p.1、3「業務内容に関する事項」: 提案内容等を踏まえて受託候補者と協議・調整し、仕様を決定する。
- PDF p.1、4(1)「契約の方法」: 契約内容は市との協議の上、仕様書及び企画提案書に基づき決定する。
- PDF p.3、7(2)オ「回答の公表」: 質問回答は参加者全員へEメールで回答する。一般公開本文を確認したという意味ではない。
- PDF p.7、9「契約の締結に関する事項」: 齟齬時は質問回答→仕様書→企画提案書等の順で扱い、企画提案書が質問回答・仕様書の水準を上回る部分はその部分に限って企画提案書を優先する。
