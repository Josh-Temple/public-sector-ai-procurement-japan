# Source notes

公開実施要領。

主な確認事項:
- Difyを用いたRAG・AIワークフロー・AIエージェント等の汎用開発プラットフォームを導入
- 神戸市が契約するMicrosoft Azure環境上で開発予定
- FY2025の調達範囲は設計・開発
- FY2026以降の運用保守は設計・開発事業者と別途随意契約する予定。ただし予算不成立時は契約しない場合がある
- 契約内容は神戸市と協議のうえ、仕様書及び企画提案書に基づき決定
- 仕様書の一部には情報資産のセキュリティ事項等が含まれ、関係資料は秘密保持誓約書提出者へ配布
- 質問回答は全参加者へ電子メール
- 評価は100点（内容80、価格20）

## Reuse caution

公開実施要領は高レベルのプラットフォーム構成と評価軸を確認できるが、非公開仕様書・質問回答・採択提案を含む契約最終要件は公開資料だけでは再構成できない。
