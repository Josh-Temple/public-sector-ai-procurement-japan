# Source notes

質問は2025年4月25日まで受け付け、回答は参加申出書を提出した者全員へ電子メールで配布すると定める。

公開ページには質問回答本文へのリンクがないため、公開資料だけでは質疑による仕様変更・解釈を完全に再構成できない。

別紙2「機能要件一覧」は提案時の提出物であり、仕様書は「必須」とされた要件をすべて満たすよう求める。

## Reuse caution

仕様書・評価表が公開されていても、非公開の参加者向けQ&Aが存在するため、「公開仕様書＝応募時の最終有効要件」と断定しない。
