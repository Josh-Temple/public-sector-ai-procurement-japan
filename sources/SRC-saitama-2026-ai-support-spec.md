# Source notes

県民向け・職員向けの生成AIチャットボットについて、AIエージェント/RAG、根拠表示、Web参照、Box連携、利用規模、セキュリティ、運用を定める公式仕様書。

## Evidence locators

- PDF p.1「提案書作成における留意点」: 候補事業者の提案を踏まえて調達仕様書を作成し、調達仕様書と提案書を本業務の仕様として契約する。提案事項・追加提案は原則として業務内で実施する。
- PDF p.3、2.3(1)-(11): AIエージェント/RAG、ナレッジ領域分離、参照文書表示、根拠なし時の不明回答、50MB以上、対応形式、表認識、Web検索、指定Webサイト、Box連携。
- PDF p.4、2.4-2.6 / P-04〜P-10: 回答精度向上、利用上限・ログ、複数LLM、AIエージェント・根拠表示・ハルシネーション防止等の提案事項。
- PDF p.5、3.1-3.2: 学習利用禁止、処理後のLLMサーバ保存禁止、国内データ保存、6チャットボット、県民アカウント不要、職員200人以上・同時50人以上。
- PDF p.6、3.2(4)-(5)・3.4-3.5: 県民1業務月200件以上、職員1業務月700件以上、24時間365日、稼働率99.5%目標。

## Reuse caution

公開仕様は公募時の要求・提案事項を示す。仕様書冒頭により、候補者の提案内容を踏まえて最終調達仕様を作成し、提案書も契約仕様に含まれるため、公開仕様だけを契約最終要件とみなさない。
