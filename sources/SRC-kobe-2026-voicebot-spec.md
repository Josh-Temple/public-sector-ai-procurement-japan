# Source notes

仕様書はサービス要件を「最低限」と明記する。

重要な機能境界:
- 音声・文脈理解にはAI技術を用いる
- 市民への回答は市提供FAQを基にした回答データから行う
- AIによる回答生成は認めない
- 基本応答時間は3秒以内
- 違和感のない待機案内等で時間をつなぐ場合は5秒程度まで許容
- 職員転送は個別職員ではなく課・係単位を想定
- 会話・応答・操作ログを録音を含めて保持し、音声やCSV等でエクスポート
- 機密性2以上の情報を取得する場合があることを前提にセキュリティ適合審査等へ協力

## Reuse caution

このSourceだけから契約最終仕様を確定しない。実施要領上、非公開の質問回答が仕様書より優先し、上位提案も一部契約条件になり得る。
