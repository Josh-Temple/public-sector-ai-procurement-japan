# Source notes

第20項は、優先交渉権者と契約交渉し合意後に随意契約を行うと定める。また、契約交渉中に契約書案および仕様書の内容を一部変更する場合があると明記。公募時仕様や選定結果だけから契約最終条件を確定しない。
