# Source notes

2026年度の生成AIサービス導入支援業務の公式仕様書。

事業目的は、RAGを含む生成AI活用の有効性・リスク・運用方法を「検証（実証）」し、その結果を分析・評価して、次段階の本格導入に向けた要件・体制・運用ルール・ガバナンスを整理すること。

したがって、2026年度案件自体を本格導入済みの本番調達として扱わない。
